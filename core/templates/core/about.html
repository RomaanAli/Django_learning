About us

Programming education, at your own pace

We are building an online e-learning platform where students can learn programming step by step — structured lessons, real practice, and no fixed schedules. This project is built with Django.

Our mission

Make quality programming education accessible

Our mission is to give every student a clear path into software development. Instead of scattered tutorials, learners get courses that are ordered, complete, and easy to follow — so it is always obvious what to learn next and how far you have come.

The whole platform runs on Django, from the course catalog to enrollment and payments, which keeps the experience fast, consistent, and easy to extend with new content.

What students can learn

Skills that build on each other

A focused catalog that grows with you from first line of code to finished project.

  • Python fundamentals — the core language skills every course on the platform builds upon.
  • Django web development — templates, views, models, and building full web applications.
  • Flask — a lightweight alternative for smaller, quick-to-build services.
  • SQL & databases — storing, querying, and reasoning about your application's data.
